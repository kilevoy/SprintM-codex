# Ядро калькулятора ограждайки: извлечённая схема

Источник: `Y:\Предварительные расчеты\Калькуляторы\Калькулятор ограждайки v1.5.xlsx`.

SHA-256 исходной книги: `4A9343A1E3149954DEC0F91D5398528F18016A8423EC204CE2B92A59F612DEAF`.

Книга содержит листы `Лист1`, `Расчет Угловая`, `Расчет Рядовая` и справочные листы ветра.

## Передача входов

`Лист1` передаёт на два расчётных листа:

- длину расчётной стены `B11`;
- высоту расчётной стены `B12`;
- шаг стоек `B13`;
- тип покрытия `B18`;
- профлист `B19`;
- максимальный и минимальный шаги `B22:B29`;
- ограничения профиля `B32:B36`.

Для торцевой стены `B12` должен быть высотой по коньку. Для продольной стены — высотой карниза.

## Подбор допустимого шага

На расчётном листе шаги перебираются от 500 до 3000 мм с шагом 10 мм. Для каждого шага проверяются ограничения `JW`:

```excel
=IF(AND(
  JW$2>=Лист1!$B$23,
  JW$2<=Лист1!$B$24,
  $I7,
  $K7,
  $M7<=$M$4,
  $M7>=$M$5,
  $N7>=Лист1!$B$34,
  $N7<=Лист1!$B$33,
  $Q7,
  $U7=$B$11,
  AD7<=1,
  $S7
),1,0)
```

Проверка использования сечения:

```excel
=AD$6/$X7
```

Изгибающий момент для шага:

```excel
=(AD5*AD2/1000)*Лист1!$B$13^2/8
```

## Выбор профиля

После проверки допустимости Excel ранжирует варианты по формуле `TQ`:

```excel
=IF(JW7=0,999999999,
  TQ$4*$Z7+
  $TO7*Лист1!$B$13+
  TQ$3*$AA7+
  $G7/1000000-
  TQ$2/1000000000+
  $TN7*Лист1!$B$13+
  $T7)
```

Результат выбирается через матрицу `AWX:BGN`:

```excel
BGS7 = INDEX($AWX$2:$BGN$2,1,MATCH(BGQ7,AWX7:BGN7,0))
BGT7 = INDEX(AWX19:BGN19,1,MATCH(BGS7,$AWX$2:$BGN$2,0))
BGU7 = INDEX(AWX31:BGN31,1,MATCH(BGS7,$AWX$2:$BGN$2,0))
BGR7 = BGQ7*$ADI$1
```

`Лист1` забирает эти значения в `B49:I50` для угловой и рядовой зон.

## Передача результата в ведомость

```excel
F49 = CEILING(B12*1000/D49,1)+IF(OR(K49="[]",K49="][",K49="[-]"),0,1)
G49 = F49*E24/B13
H49 = INDEX('Расчет Угловая'!AA7:AA870,MATCH(B49,'Расчет Угловая'!V7:V870,0),1)*G49
I49 = F49*E24*INDEX('Расчет Угловая'!Z7:Z870,MATCH(B49,'Расчет Угловая'!V7:V870,0),1)
```

Для рядовой зоны используются `E29` и округление количества кронштейнов:

```excel
G50 = CEILING(F50*ROUND(E29/B13,1),1)
```

## Статус переноса

Таблица `V:AA` извлечена воспроизводимым скриптом
`scripts/extract_wall_envelope_profiles.py`; результат хранится в
`src/data/wallEnvelopeProfiles.generated.json` и содержит SHA-256 исходной книги.
Повторное извлечение выполняется командой:

```powershell
python scripts/extract_wall_envelope_profiles.py <путь-к-книге.xlsx> \
  --output src/data/wallEnvelopeProfiles.generated.json
```

Помимо массы `Y:AA`, в снимке сохранены несущая характеристика `X` и
признаки соединения `Q/S`, необходимые для следующего этапа автоматического
подбора.
Модуль `src/calc/wallEnvelope/wallEnvelope.ts` воспроизводит прозрачную часть
расчёта рядов, длины профиля и массы по явно выбранной строке каталога. Он
возвращает статус `provisional` и не подменяет текущий подбор каркаса.

Автоматический выбор по ветровым таблицам `AD4`, ранжирование `TQ` и полная
сверка зон ещё не завершены. До паритета на `21876`, `22317` и `22012` строку
профиля нужно передавать явно; это сделано намеренно, чтобы не превращать
объектную формулу `21876!C35` в неподтверждённое универсальное правило.
