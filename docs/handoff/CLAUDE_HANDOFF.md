## Цель

Довести расчёт холодного ангара с профнастилом до подтверждённого Excel-паритета:
автоматически подобрать стеновые прогоны по угловой и рядовой зонам, посчитать
кронштейны, крепёж, массы и стоимость, а затем включить результат в ведомость.

## Что уже сделано

- Добавлен снимок 864 строк каталога из `Калькулятор ограждайки v1.5.xlsx`:
  `src/data/wallEnvelopeProfiles.generated.json`.
- Добавлен воспроизводимый extractor:
  `scripts/extract_wall_envelope_profiles.py`.
- Добавлено изолированное ядро:
  `src/calc/wallEnvelope/types.ts` и `wallEnvelope.ts`.
- `computeProject` принимает необязательный блок `wallEnvelope` и возвращает
  provisional-результат для продольных стен и торцов.
- Торцевые стены используют высоту по коньку, продольные — высоту по карнизу.
- Снимок содержит массу `Y:AA`, несущую характеристику `X` и признаки `Q/S`.
- Локальный Excel-прайс не добавлен в Git.

## Что пока нельзя считать готовым

- Автоматический подбор профиля по ветровой таблице Excel ещё не перенесён.
- Формулы `AD4`, `JW`, `TQ`, `BGQ:BGR:BGS:BGT:BGU` не подтверждены построчным
  паритетом в TypeScript.
- Стеновые прогоны пока не входят автоматически в коммерческий итог.
- `wallEnvelope.status = "provisional"` обязателен до завершения проверки.
- Не подгонять ожидаемые значения под SprintM.

## План следующего этапа

1. Извлечь из `Расчет Угловая` и `Расчет Рядовая` все колонки, участвующие в
   условии `JW`, ранжировании `TQ` и матрице результата `AWX:BGN`.
2. Извлечь таблицу коэффициентов ветра `AD4` и зафиксировать её связь с
   существующими климатическими справочниками SprintM.
3. Реализовать чистую функцию выбора профиля:
   входы — тип зоны, длина стены, высота, шаг рам, тип местности, ветровое
   давление, материал, утеплитель, границы шага;
   выход — профиль, шаг, коэффициент использования, масса и причина выбора.
4. Сверить вручную и тестами формулы:
   - `AD6`, `AD7`;
   - `JW`;
   - `TQ`;
   - `F49:I50` на `Лист1`.
5. Добавить отдельные строки для стеновых прогонов, кронштейнов, уголков и
   крепежа в ведомость. Стоимость окон, ворот и дверей не включать в
   сопоставимую стоимость.
6. Проверить проёмы: вычеты из площадей, влияние на ряды, оконные ригели и
   обрамление.
7. Проверить режимы поставки:
   - полный комплект с профнастилом;
   - только каркас под профнастил — стеновые прогоны нужны;
   - только каркас под сэндвич-панели — стеновые прогоны исключать только по
     составу поставки;
   - кровельные прогоны учитывать отдельно.
8. После каждого изменения запускать:

```powershell
npm.cmd run verify
```

9. До подтверждения трёх независимых книг оставлять статус `provisional`.

## Критерий готовности

Минимум три независимые книги дают подтверждённый построчный Excel-паритет по
профилю, шагу, количеству рядов, длине, кронштейнам, массе и стоимости без
окон, ворот и дверей. Только после этого можно убрать provisional и включить
автоподбор в пользовательскую форму.
