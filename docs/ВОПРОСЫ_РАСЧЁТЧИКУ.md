## 3. Заготовка формул на неактивных листах — ей можно пользоваться?

На листах, которые сейчас не задействованы, лежат готовые формулы
стенового ограждения под сэндвич:

```
стр34 [нс]  ((C10+0,5)/1,2+1)*(C8+C9)*2*1,1[*2]    ← прогоны, шаг 1200
стр35 [сс]  (C8+C9)*2/C11*(C10+0,5)*2*1,1 + <проёмы>  ← стойки
стр36 [цок] 2*(C8+C9)*2                             ← цокольный профиль
```

Между листами они расходятся: где-то `+0,5`, где-то нет; где-то `*2`,
где-то нет; на одном листе шаг `/2` вместо `/1,2`. В пределах одного
листа 21777!21 в строке 34 надбавки `+0,5` нет, а в строке 35 есть.

**Вопрос 3.** Это рабочий вариант расчёта ограждения под сэндвич, от
которого отказались, или просто мусор от старых проектов? Если рабочий —
какая из редакций верная, и почему шаг 1200 зашит вместо подбора?

## 5. Кронштейны: цена НАЙДЕНА, но единица измерения не сходится

**Источник цены — прайс, вопрос 5а закрыт:**

```
«Прайс для предрасчетов (не изменять).xlsx», лист «Профлист,доборы»
  B78 = "Кронштейны (огр.констр.)"          ← заголовок блока
  B79 = "Угол специальный 90 гр. 2,0 П350 (Оцинк.)"
  C79 = 2206 ₽/п.м.   (тянется из 1С: 'Вставить из 1с сюда'!G2035)
  E79 = C79*0,24 = 529,44
  F79 = "шт"
```

То есть кронштейн — это отрезок **0,24 м** специального угла 90° 2,0 П350
оцинкованного, и 529,44 ₽ — цена **за штуку**, а не за погонный метр.

**Вопрос 5а (новый). Единица не сходится с ведомостью.** В прайсе `F79`
стоит «шт», а в ведомости `D38` — «п.м.». Стоимость при этом сходится на
трёх объектах, потому что числа перемножаются одинаково, но смысл разный.

**Вопрос 5б. Множители 0,75 и 0,2 против 0,24 из прайса.**

```
ведомость:  C38 = G38 / 0,75 * 0,2        → 90 кг дают 24
прайс:      один кронштейн = 0,24 п.м. по 2206 ₽/п.м.
```

Если 0,75 кг — масса одного кронштейна, то в 90 кг их 120 штук, и при
0,24 м это 28,8 п.м., а не 24. Откуда 0,2?

**Вопрос 5в. Сколько всё-таки кронштейнов?** SprintM считает их из
подбора: 60 шт по 1,5 кг (`'Расчет Угловая'!AA` для сечения `[]`) = 90 кг
— масса сходится с `G38` ровно. Ведомость же из тех же 90 кг получает 24.
60 против 120 против 24 — какое число настоящее?

Стоимость сейчас считается по формуле ведомости и совпадает до копейки
(12 706,56 на 21876, 16 518,53 на 22258, 29 225 на 22304), поэтому
поведение я не менял. Но пока смысл множителей неясен, на нестандартном
объекте это может разъехаться.
